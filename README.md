# Pricing Page

A responsive pricing page built using HTML, CSS, and JavaScript. It displays three subscription plans — Basic, Professional, and Master — with monthly and annual billing options.

## Features

- Three pricing plans: Basic, Professional, and Master.
- Monthly and annual billing toggle.
- Professional plan highlighted by default.
- Responsive layout for desktop, tablet, and mobile devices.
- Dynamic price updates using JavaScript.
- Custom styling with gradient backgrounds and decorative SVG images.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)

## Getting Started

### 1. Clone the Repository

```bash
git clone <repository-url>

```

### 2. Navigate to the project directory

```bash
cd pricing-page

```

### 3. Run the project

Open index.html in your browser, or use the Live Server extension in Visual Studio Code.
